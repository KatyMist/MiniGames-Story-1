# MiniGames

Учебный проект «MiniGames» — квалификационный этап RS School (Story 1).

Одностраничное приложение (SPA) на чистом TypeScript без фреймворков: адаптивная главная страница и диалоговое окно авторизации, свёрстанные по макету Figma.

## Стек

- TypeScript
- Vite
- Sass
- ESLint + Prettier
- Husky

## Запуск проекта

```bash
npm install
npm run dev
```

Приложение будет доступно по адресу, который выведет Vite (обычно `http://localhost:5173`).

## Сборка

```bash
npm run build
```

Собранные файлы появятся в папке `dist`.

## Скрипты

- `npm run dev` — запуск в режиме разработки
- `npm run build` — сборка для продакшена
- `npm run lint` — проверка кода ESLint
- `npm run format` — форматирование кода Prettier
