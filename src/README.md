# Структура проекта

- `app/` — инициализация приложения, роутинг
- `pages/` — страницы (каждая в своей папке: разметка + стили страницы)
- `components/` — переиспользуемые UI-компоненты (шапка, футер, диалоги и т.д.)
- `shared/` — общие утилиты, константы, общие UI-элементы
- `styles/` — токены дизайна, миксины, глобальные стили (Sass)
